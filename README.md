# FastAPI ToDo Lists

Приложение для управления списками задач для нескольких пользователей

## Стек технологий
- **FastAPI** (Backend)
- **SQLAlchemy 2.0** (ORM)
- **UV** (Package manager)
- **PostgreSQL** (Data Base)

## Как запустить
1. Установите `uv` (если нет)
2. Выполните `uv sync`
3. Запустите: `uv run uvicorn src.main:app`
